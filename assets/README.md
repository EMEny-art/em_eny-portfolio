# assets/ README

Questa cartella contiene un file placeholder `em_eny-desk.svg` usato nella hero.

Per migliore performance sostituisci il file con una versione ottimizzata in formato WebP chiamata `em_eny-desk.webp`.

Consigli per l'immagine:
- Risoluzione consigliata: 1200px di larghezza (massimo 1600px)
- Formato: WebP per la migliore compressione/qualità
- Aggiungi attributi width/height per evitare layout shift

Per sostituire:
1. Metti il file ottimizzato in `assets/em_eny-desk.webp`.
2. Aggiorna `index.html` se vuoi cambiare il nome del file.
