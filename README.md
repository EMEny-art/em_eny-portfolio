# em_eny-portfolio

Sito portfolio per EM_ENY — ottimizzato per accessibilità, performance e interattività.

Questo repository contiene una versione del sito con:

- Skip link per accessibilità
- Menu mobile funzionante (aria-expanded, chiusura con Escape)
- Pulsante "Copia" che copia il tag Discord in clipboard
- Reveal on scroll con IntersectionObserver
- Asset placeholder in `assets/` (sostituisci con la tua immagine ottimizzata)

Live (GitHub Pages): https://EMEny-art.github.io/em_eny-portfolio/ (può impiegare qualche minuto per il primo deploy)

Come personalizzare

- Sostituisci `assets/em_eny-desk.svg` con una immagine ottimizzata WebP/PNG/JPEG chiamata `em_eny-desk.webp` per migliori performance.
- Modifica contenuti direttamente su `index.html` o apri una Pull Request per cambi maggiori.
